# 🏗️ AI产业链主线轮动监测系统 V1.0 · 架构需求书

> **总原则（放 README 最上面）**：
> 本系统不是预测股票涨跌，而是持续识别AI产业链中"盈利 → 资金 → 相对强度 → 成交定价权"的迁移过程；不因为故事买入，只因为数据逐级通过Gate而提高仓位；不因为恐慌卖出，只因为TPO信号逐级确认而降低仓位。

---

## 一、系统最终要解决的问题

系统每天回答五个问题：

1. 现在第一主线是谁？
2. 第二曲线有没有开始获得资金和定价权？
3. 资金结构有没有发生变化？
4. 哪条产业链进入了哪个R阶段？
5. 有没有TPO撤退信号？

### 监控范围（V1.0，不无限扩张）

**第一曲线（AI算力）**：中际旭创、新易盛、海光信息、澜起科技、北方华创、中微公司、兆易创新、沪电股份

**第二曲线 - PCB/CCL**：沪电股份、深南电路、生益电子、胜宏科技、生益科技

**第二曲线 - 液冷**：英维克、同飞股份、高澜股份、申菱环境

**第二曲线 - AI电源**：科士达、麦格米特、科华数据、欧陆通

## 二、六层架构

```
第一层：原始数据采集（Raw Data，永远保存不覆盖）
        ↓
第二层：数据清洗/校验（多源交叉验证）
        ↓
第三层：指标计算（T/L/M/E 四维）
        ↓
第四层：产业链状态判断（R0-R4）
        ↓
第五层：交易规则引擎（Gate 1/2/3 + TPO）
        ↓
第六层：早报/盘报/预警/分享（JSON + Markdown）
```

> **核心纪律**：原始数据和判断彻底分开。任何判断都能反查：由哪些原始数据计算出来。
> **工程原则**：不允许"抓到数据→AI猜→输出可以买"。必须"原始数据→数学指标→规则判断→状态→人做最终投资判断"。

## 三、第一层：原始数据采集

### A. 行情数据（每只股票）

| 字段 | 必须 |
|------|------|
| 股票代码/名称/日期/时间 | ✅ |
| 开盘/最高/最低/收盘 | ✅ |
| 涨跌幅 | ✅ |
| 成交额/成交量 | ✅ |
| 换手率 | ✅ |
| 总市值/流通市值 | ✅ |

**衍生（由历史行情计算）**：5D/10D/20D/60D/120D/250D 涨跌幅

### B. 相对强弱数据（RS）

股票相对于以下基准的 5D/10D/20D/60D RS：
- 沪深300、创业板指、科创50
- 申万电子、申万计算机
- 对应产业链指数
- 第一曲线、第二曲线

### C. 资金数据（必须记录 source + definition + timestamp）

每日：主力净流入、超大单/大单/中单/小单、北向/陆股通、融资买入、融资余额变化
滚动：5D/10D/20D 资金净流入

### D. 成交结构

- 个股在全市场/电子/通信/PCB/液冷/电源中的成交额排名
- 成交额占比：PCB/AI硬件、液冷/AI硬件、电源/AI硬件
- AI资金结构：光模块% / 芯片% / PCB% / 液冷% / 电源% / 其他%

### E. 涨跌结构（产业链宽度）

每产业链统计：涨幅分布（>5%/3-5%/0-3%/0--3%/-3--5%/<-5%）、上涨/下跌家数、涨停/跌停、创新高/创新低
→ 自动识别"板块扩散"vs"单龙头行情"

### F. 估值数据

PE-TTM、PE-2026E、PE-2027E、PB、PS、PEG、近3年/5年估值分位
→ 用途：判断盈利有没有追上股价（EPS预期+10%但股价+50%=PE扩张36%=TPO信号）

### G. 基本面数据（区别于普通量化的核心）

每个财报周期记录：营收/同比/环比、净利润/同比/环比、扣非净利润/同比、毛利率、净利率、ROE、经营现金流/同比、应收账款、存货、资本开支、合同负债、在手订单、产能、产能利用率

### H. 主线收入归因（强制字段）

Mainline Revenue Attribution：收入增长中，多少来自AI主线。
例：营收+60%，其中AI数据中心PCB+75%/传统+10%/消费-5%/汽车+8%

### I. 基本面四状态（F0-F3）

| 状态 | 定义 |
|------|------|
| F0 | 没有明确主线盈利 |
| F1 | 主线已进入收入 |
| F2 | 主线进入利润 |
| F3 | 主线成为主要增长来源 |

> F0/F1 的未来故事不能进入盈利兑现评分。

### J. 订单数据 + Order Evidence Level

| 等级 | 定义 |
|------|------|
| O0 | 没有证据 |
| O1 | 公司表述 |
| O2 | 已有订单 |
| O3 | 已批量交付 |
| O4 | 已进入财务报表 |

### K. 宏观层（只5个）

Nasdaq、SOX、NVDA、美国10Y、A股科技成交额
辅助：美股AI核心表现、大宗商品/油价异常、人民币汇率

## 四、第三层：四个核心维度（T/L/M/E）

| 维度 | 内容 |
|------|------|
| **T Trend 趋势** | 5D/10D/20D/60D、均线、新高/新低、趋势结构 |
| **L Leader 中军** | 龙头是否继续强？一个龙头强还是多个核心同步强？ |
| **M Money 资金** | 5D/10D Flow、成交额、成交额占比、资金结构、融资 |
| **E Earnings 盈利兑现** | 主线收入、主线利润、毛利率、扣非、OCF、订单、EPS预期 |

---

## 五、第五层：闸门系统（Gate 1/2/3）

| Gate | 条件 | 达到状态 | 动作 |
|------|------|---------|------|
| **Gate 1** | 产业逻辑 PASS + 基本面 PASS（F≥1, O≥2） | R1 | 只能观察 |
| **Gate 2** | + RS5>0、RS10>0、成交额占比提升、5D资金改善、≥2核心同步（5项≥4） | R2 | 允许小仓试错 |
| **Gate 3** | 老主线弱化 + 新主线强势 + 新主线资金占比提高 + 新主线基本面继续强化 | R3 | 允许真正迁仓 |

## 六、R 状态机

```
R0 观察 → R1 基本面确认 → R1.5 等待资金 → R2 小仓试错 → R2.5 加仓准备 → R3 主线共振 → R4 高位拥挤/TPO
```

---

## 七、TPO 撤退信号（独立于 Gate，单独计分）

| 信号 | 含义 |
|------|------|
| TPO-1 | 相对强度见顶 |
| TPO-2 | 资金与价格背离 |
| TPO-3 | 龙头开始掉队 |
| TPO-4 | 估值扩张明显超过盈利 |
| TPO-5 | 放巨量但价格不再上涨 |
| TPO-6 | 订单/收入/利润预期下降 |
| TPO-7 | 产业链内部广度明显恶化 |

| TPO 计分 | 动作 |
|----------|------|
| 0 | 正常 |
| 1 | 警戒 |
| 2 | 减仓准备 |
| 3 | 主动减仓 |
| 4 | 主线撤退 |

## 八、第一曲线 vs 第二曲线（系统灵魂）

每天自动计算：

| 指标 | 第一曲线 | 第二曲线 |
|------|---------|---------|
| 5D RS | | |
| 10D RS | | |
| 20D RS | | |
| 5D Flow | | |
| 10D Flow | | |
| 成交额 | | |
| 成交额占比 | | |
| 核心股同步率 | | |
| 基本面评分 | | |
| 估值评分 | | |

→ 输出 **Migration Score**：AI资金/定价权有没有从第一曲线向第二曲线扩散。

### 反迁移指标（避免自己骗自己）

第二曲线上涨，到底是自己强还是第一曲线休息？
必须看：PCB RS↑ + PCB Flow↑ + PCB Turnover Share↑ + PCB Breadth↑ + PCB Earnings↑
不同步 → 非迁移，仅轮动/反弹。

## 九、输出

### 每日三个文件

1. `AI_INFRA_DAILY_PACKET.json` — 给用户分析
   ```json
   {date, market, macro, first_curve, pcb, cooling, power, migration, tpo, portfolio, alerts}
   ```
2. `AI_INFRA_DAILY_REPORT.md` — 人类可读版
3. `AI_INFRA_ALERT.json` — 异常预警

### 早盘数据包（开盘前）

A. 全球环境（Nasdaq/SOX/NVDA/10Y）
B. 第一曲线（中际/新易盛/海光/澜起 的 RS5/RS10/昨日Flow/趋势）
C. 第二曲线（沪电/深南/生益电子/胜宏/生益科技 的 RS5/RS10/Flow/成交额）
D. 液冷4只
E. 电源4只
F. 自动状态（R阶段 + Migration Score + TPO）

### 盘后数据包（比早盘更重要）

当日：收盘价/涨跌/成交额/换手/主力资金/融资/RS/板块宽度 + 5D/10D/20D滚动
→ 自动输出"今日发生了什么"（例：光模块核心同步2/2 Flow改善RS10继续领先→第一曲线继续强；PCB核心同步4/4成交额占比+3.2pct→R1.5→R2）

### 异常雷达（自动标红）

- 核心股票单日跌幅>5%
- 5D RS突然恶化
- 资金连续3日流出
- 放巨量不涨
- 基本面预期下调
- 产业链核心同步率下降
- 第一曲线和第二曲线重大结构变化

### 盘中事件包（Intraday Event Packet）

标准化输出：时间 + 个股（价格/成交额/主力/RS5）+ 第一曲线/第二曲线同步表现 + 事件等级

### 三个分享按钮

- 🟢 早盘分享 → `AI_INFRA_AM_YYYYMMDD.json`
- 🔵 盘后分享 → `AI_INFRA_PM_YYYYMMDD.json`
- 🔴 异常分享 → 只分享重大变化数据

## 十、工程要求

1. **Raw Data 永远保存不覆盖**：`raw/YYYY-MM-DD/{market,flow,finance,news}/` → `clean/` → `indicator/` → `signal/` → `decision/` 分层
2. **多源交叉验证**：Source A/B/C → Data Adapter → 统一字段 → 一致性检查（不一致标记异常，不偷偷选）
3. **机器算数据，人做决策**：系统只输出状态，不输出"可以买"
