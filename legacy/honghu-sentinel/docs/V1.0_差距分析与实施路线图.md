# 🔍 V1.0 差距分析与实施路线图

> 标注：✅ 已实现 · 🟡 部分实现 · ❌ 未实现

---

## 一、第一层：原始数据采集

| 数据类 | 需求 | 现状 | 缺口 |
|--------|------|------|------|
| **行情** | 开高低收/涨跌/成交额/成交量/换手/总市值/流通市值 + 5/10/20/60/120/250D | 🟡 有收/涨跌/成交额/5D/10D/20D | 缺开高低、换手、市值、60/120/250D |
| **RS** | 对沪深300/创业板/科创50/申万电子/申万计算机/产业链指数/第一曲线/第二曲线 的 5/10/20/60D RS | 🟡 仅对第一曲线基准的5D/10D RS | 缺大盘/行业基准、缺20/60D |
| **资金** | 主力/超大单/大单/中单/小单/北向/融资 + 5/10/20D Flow + source/definition/timestamp | 🟡 仅主力1日/5日（东财f62+fflow） | 缺超大单/大单/中单/小单/北向/融资/10D/20D、缺元数据 |
| **成交结构** | 成交额排名、成交额占比（PCB/液冷/电源 ÷ AI硬件）、AI资金结构饼图 | 🟡 仅PCB/第一曲线一个比值 | 缺排名、液冷/电源占比、饼图结构 |
| **涨跌结构** | 涨幅分布、上涨/下跌家数、涨停/跌停、新高/新低、产业链宽度 | ❌ | 完全缺 |
| **估值** | PE-TTM/26E/27E、PB、PS、PEG、3/5年分位 | ❌ | 完全缺 |
| **基本面** | 财报周期数据库（营收/利润/扣非/毛利率/ROE/OCF/应收/存货/资本开支/合同负债） | 🟡 档案静态字段 | 缺周期数据库、缺自动更新 |
| **主线收入归因** | Mainline Revenue Attribution | ❌ | 完全缺（需人工录入+结构化） |
| **F0-F3状态** | 主线盈利四状态 | ❌ | 完全缺 |
| **订单数据** | 新订单/在手/产能 + O0-O4证据等级 | ❌ | 完全缺 |
| **宏观** | Nasdaq/SOX/NVDA/10Y/A股科技成交额 | ❌ | 完全缺 |

## 八、实施路线图（分阶段）

### 阶段 0：地基（9/9-9/10，已完成）
- ✅ 架构需求书落库
- ✅ Day 0 基准值（18项作战表）
- ✅ README 总原则
- ✅ 现有快照每日跑（5日观察实验）

### 阶段 1：Raw Data 分层 + 行情补全（9/10-9/12）
**目标**：原始数据与判断分离，所有数据可追溯
- [ ] 建立 `raw/YYYY-MM-DD/market/` 目录，每日原始行情JSON归档（不覆盖）
- [ ] 行情补全：开高低、换手、总市值、流通市值、60/120/250D
- [ ] 多源交叉验证：东财 vs 腾讯收盘价一致性检查，不一致标 `⚠️`
- [ ] 资金元数据：每条主力资金记录 source=eastmoney + definition + timestamp

### 阶段 2：宏观 + RS基准扩展（9/12-9/14）
**目标**：5个宏观指标 + 多基准RS
- [ ] 宏观5项：Nasdaq/SOX/NVDA/10Y/A股科技成交额（腾讯美股.US前缀或新浪）
- [ ] RS扩展：对沪深300/创业板指/科创50/申万电子 的5/10/20/60D RS
- [ ] 输出：每只股票的 RS 矩阵

### 阶段 3：资金 + 成交结构（9/14-9/16）
**目标**：M维度完整
- [ ] 资金扩展：超大单/大单/中单/小单（东财fflow）、10D/20D Flow
- [ ] 成交额占比：PCB/液冷/电源 ÷ AI硬件，每日变化

- [ ] 产业链宽度：涨幅分布、上涨/下跌家数、涨停/跌停、新高/新低
- [ ] **到9/16正好5日数据，可判定 Gate2 ③成交额占比连续5日升**

### 阶段 4：R状态机 + Gate + TPO（9/16-9/20）
