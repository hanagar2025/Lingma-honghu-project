## 为什么不并行运行

主程序已有资金驾驶舱（R-01，`backend/src/services/moneyRadar/`），覆盖同一件事，而且更严格：

| 方面 | 资金哨兵 | 资金驾驶舱 R-01 |
|---|---|---|
| 持仓名单 | 代码里写死 8 只（含已清仓的澜起、兆易，缺深南） | 直接读账本 `portfolio.json` |
| 资金状态机 | 5 日均额对 20 日均额，阈值随手设定 | 7 态状态机，阈值预先登记、校准一次后冻结 |
| 价资关系 | 3×3 矩阵，融资净买入缺失时退回「主力净流入（估算）」 | 背离四条件，估算数据不投票，A2 存量数据确认 |
| 行业雷达 | 东财一级行业 31 个 | 申万二级 134 个 |
| 打分 | 有加权分（`_weighted`、`fund_score`） | 不打综合分（治理规则） |
| 动作 | `_compute_action_list` 会写「减至~15%」「清仓」 | 观察层不产生动作 |
| 运行 | Mac launchd + 本地研究库目录 + CloudBase + 微信 | GitHub / 服务器，PushPlus 与网页沿用主程序 |

两套并行会出现两种资金结论。最后两行与委员会规则直接冲突：观察层不得出买卖动作，不打综合分。
