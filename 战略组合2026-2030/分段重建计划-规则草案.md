# 分段重建计划：规则草案 v0

状态：草案，不生效。委员会 11/11 同意由研究层起草。本文件不授予任何买入权限。

生效需要依次完成四步：
1. 委员会对第七节的事项逐项裁定。
2. 参数候选集登记（在回测之前）。
3. 回测，按登记的评判标准选定参数。
4. 模拟层运行并验收，委员会正式批准。

---

## 一、定位

- 来源：10/27《下一步战略》第三步的方向丙。不改回撤规则，另立一个有上限的"重建额度"。
- 重建额度是现有规则之内的买入许可，不是豁免。以下规则全部照旧：
  - 三条卖出规则：C 级清退、单票 12%、熔断。
  - 股票总仓位上限、AI 主题 45%、单一板块 30%、现金不低于 10%。
- 没有重建额度时，"只卖不买"照常。
- 卖出永远不需要本计划的任何前提。

## 二、可买范围

同时满足以下三条的股票才在范围内：

1. 在四条主线的冠军池内。
2. 产业验证、盈利验证、主线归因三项均已核验。
3. 最新一期财报通过第三节的前提五。

按 11/10 的读数，候选是中际旭创、沪电股份、深南电路。

- 生益科技：证据等级 A，不在冠军池，三项核验未建档。完成研究升级后才进入范围。
- 新易盛：在冠军池内，但三季度扣非利润环比下滑，不通过前提五。
- 宁德时代：不在四条主线内，不在范围内。
- 范围随每期财报更新；名单本身不是买入建议。

## 三、前提

六项必须同时成立。每项都是可复算的读数，出处和取数时间随记录保存。标"待定"的参数由回测决定。

| 编号 | 前提 | 判定方式 | 待定参数 |
|---|---|---|---|
| 一 | 账户干净 | 账本日期不早于上一交易日；执行单正常出单；没有未完成的卖出指令（单票归位、C 级清退、熔断补足） | 无 |
| 二 | 个股止跌 | 该股最近 N 个交易日的收盘价没有创 60 日新低 | N |
| 三 | 去杠杆结束 | 光模块去杠杆三信号成立（参数登记 v1）。只适用于光通信主线的股票；其他主线用该股融资余额的同类读数 | 见参数登记 |
| 四 | 海外链条止跌 | 英伟达，以及 Lumentum、Coherent 的等权组合，最近 M 个交易日的收盘价都没有创 60 日新低。只适用于盈利来自海外资本开支的股票（光模块、PCB） | M；美股行情须有第二数据源 |
| 五 | 盈利没有掉头 | 最新一期财报：单季扣非利润环比不为负；存货的环比增速不超过营收环比增速加 X 个百分点 | X |
| 六 | 仓位有空间 | 买入后：股票总仓位不超过上限，单票不超过 12%，主题和板块不超限，现金不低于 10% | 无 |

说明：
- 前提二、三、四解决"被迫卖出的人卖完了没有"，前提五解决"是不是陷阱"。估值不设为前提：便宜不是买入理由，只在第二节里用来排序。
- 任何一项取不到数据，按不成立处理。
- 去杠杆的降速不用"个股变化率 ÷ 全市场变化率"的倍数。全市场变化接近零时倍数会失真（11/10 是 36 倍）。改用两者之差，单位为百分点。

## 四、额度与节奏

| 项 | 草案 | 待定参数 |
|---|---|---|
| 总额度 | 经本计划买入的累计市值，不超过总资产的 Q% | Q |
| 单批上限 | 每批不超过总资产的 B% | B |
| 批间隔 | 同一只股票两批之间至少间隔 G 个交易日 | G |
| 每批复核 | 每一批下单当天，六项前提都要重新成立 | 无 |
| 单票上限 | 12%，不变 | 无 |
| 资金来源 | 账户内现金。不转入新资金，不融资 | 无 |
| 预登记 | 每批下单之前写一行：股票、数量上限、六项前提当时的读数、时间。先登记后下单 | 无 |

## 五、暂停与终止

本节只管"是否继续买"。卖出仍只由三条卖出规则决定，本计划不新增卖出理由。

| 情况 | 处理 |
|---|---|
| 买入后该股收盘创 60 日新低 | 停止该股后续批次；前提二重新计数 |
| 任一前提不再成立 | 暂停全部后续批次，直到重新成立 |
| 经本计划买入的仓位，合计浮亏超过 L% | 暂停全部批次，提交委员会复盘后才能恢复 |
| 出现没有预登记的买入 | 暂停全部批次，提交委员会复盘后才能恢复 |
| 该股下一期财报不通过前提五 | 移出可买范围 |

待定参数：L。

## 六、参数怎么定

1. 先登记候选集，再回测。候选集一经登记不得增补：
   - N、M：5、10、15 个交易日。
   - G：5、10 个交易日。
   - B：2%、3%。
   - Q：10%、15%。
   - X、L：登记时给出，各不超过三个候选。
2. 回测样本：四条主线冠军池股票 2019 年以来距 250 日高点回撤超过 40% 的全部时段。分三类：反弹失败、二次下跌、趋势恢复。
3. 评判标准（登记时固定）：
   - 条件成立后 20 日、60 日内再创新低的比例；
   - 相对"回撤达到 40% 当天直接买入"的 60 日收益差；
   - 条件从未成立而错过恢复的比例。
4. 样本不足以区分候选时，取最保守的一档，并写明"未经验证"。
5. 回测通过后在模拟层运行不少于 20 个交易日。验收标准：每日读数可复算，预登记与模拟成交逐笔对得上。

2. 现有仓位的处理。11/11 截图中，中际旭创、宁德时代两只是执行单之外买入的；另有委员会告知的生益科技。建议：
   - 不追认为本计划内的买入，归档为"未预登记交易"；
   - 其中属于可买范围的部分（中际旭创归位后的仓位）计入总额度的占用；
   - 宁德时代不在四条主线内，是否保留另行裁定。
3. 是否同意"估值不设为前提"。
4. 是否同意第五节"本计划不新增卖出理由"。
5. 回测样本起点（2019 年）与候选集。
