# MA60 模拟对照报告 SIM-MA60（2026-10-16）

> 只做模拟统计，不产生动作。每日执行单不调用本报告与 MA60 规则；实盘卖出纪律仍为 C 级清退 → 单票归位 → 熔断（熔断在峰值核验前不执行、不撤销）。
> 统计价值 ≠ 卖出权限：任何结论要改执行单，必须另行提交委员会裁定。

## 摘要（股票池全部，全期）

- 方案 A：单日确认即减仓：每股每年 7.7 次信号；20 日卖错率 51.7%、60 日 54.6%；来回打脸 66.4%；平均最大回撤 -55.4%（一直持有 -62.7%，改善 7.4 个百分点）；中位总收益 315%（一直持有 638%）。
- 方案 B：连续两日确认后减仓：每股每年 5.6 次信号；20 日卖错率 53.4%、60 日 54.3%；来回打脸 55.5%；平均最大回撤 -56.5%（一直持有 -62.7%，改善 6.2 个百分点）；中位总收益 315%（一直持有 638%）。
- 方案 C：同方案 B 的信号只进入复核，不交易；回撤与收益即一直持有。
- 读法（由数据自动判断）：两种减仓方案都让平均回撤变浅；但一半以上的卖出事后看是卖错；长期收益低于一直持有；两日确认比单日确认少 28% 信号；来回打脸更少；回撤改善也更小。

## 一、口径

- 「减到 40%」指**该股票自身持仓**的 40%（卖出 60%），不是组合总资产的 40%。
- V1.0 文档两处写法不一致：第 49 行「减持至原仓位的 40% 以下（即累计至少减 60%）」，第 65 行个股示例写「减 40%」。代码 `tios/executionEngine.ts` 按前者实现；本模拟按前者计算；以哪处为准待委员会确认。
- 三种方案：
  - 方案 A：单日确认即减仓：收盘跌破当日触发；次日开盘减到该股持仓的 40%。V1.0 原条款「单日跌破 MA60 减到 40%」，保留为对照组，执行单不调用
  - 方案 B：连续两日确认后减仓：连续两日收盘低于 MA60 触发；次日开盘减到该股持仓的 40%。10/12 委员会模拟阶段候选参数
  - 方案 C：仅触发复核：连续两日收盘低于 MA60 触发；只记录、不交易。8/13 裁定现行口径：技术指标只触发复核，不单独产生卖出
- 方案 A、B 是规则候选的统计检验；方案 C 是现行口径（8/13 裁定）。

## 二、测试范围

- 样本：MSR 股票池 28 只（冻结冠军 8 只、其余 20 只），前复权日 K（腾讯）。上市晚于起点的股票从上市满 60 日起算。
- 区间：2019-01-01 至 2026-10-16；样本内 2019-01-01 至 2024-01-01 前，样本外 2024-01-01 起。基准 沪深300（sh000300）。
- 交易成本：卖出 = 佣金 0.025% + 滑点 0.10% + 印花税（2023-08-28 前 0.10%，之后 0.05%）；买回 = 佣金 + 滑点 0.125%。
- 跌停开盘无法卖出：顺延到第一个非跌停开盘日成交（科创板 20%；创业板 2020-08-24 起 20%；其余 10%；未处理 ST）。
- 「卖错率」：成交后 H 个交易日个股收益仍高于卖出成本的信号占比（卖掉的部分本可以赚回来）。「来回打脸」：信号后 10 个交易日内收盘重新站上 MA60。
- 路径回撤需要回补假设才能比较：减仓后收盘连续两日站上 MA60，次日开盘买回满仓。**回补只是计算假设，不是规则建议**；V1.0 与委员会都没有裁定回补条款。

## 七、边界

- 本报告不改变执行单：每日执行单不 import `simulation/`，审计脚本 `npm -w backend run ladder:audit` 逐条核对。
- 样本是今天的股票池（含幸存者偏差：池内股票多是事后表现好的 AI/半导体标的），结论偏向「一直持有」。
- 未模拟：盘中触发、停牌（日 K 缺失日视为无交易）、仓位在组合层的再分配、熔断与单票归位的叠加。
- 是否采用任何一个方案，由委员会依据本报告另行裁定；采用前还须接入交易所日历。
