# 主线内部新核心发现器 —— 立项书与前置条件

**状态：立项，未实现。本文件不含任何可执行决策规则。**

委员会 2026-08-13 提出下一阶段核心研发目标：

> 在已经确认的战略主线内部，谁正在从"普通公司"向"核心公司"演变？

并给出目标链条：

```
战略主线 → 产业链节点 → 利润池 → 资金迁移 → 势能变化 → 候选核心 → 价格窗口 → 仓位许可 → 执行
```

本文件回答三件事：① 这条链已经建成了多少；② 委员会给出的表述里有两处会静默恢复已被自有回测证伪的规则；③ 为什么现在**不能**动手写这个发现器，以及必须先补什么。

## 一、这条链已经建成了多少

委员会列出七个雷达。逐项核实现状：

| 雷达 | 要回答的问题 | 现状 | 位置 |
|---|---|---|---|
| TPO | 老核心是不是正在失去势能？ | **已建，但预测力已被自有回测证伪** → 降为 OBSERVATION，只触发复核，不产生动作 | `cockpit/momentum.ts` |
| MSR | 哪些标的正在获得势能？ | 已建，五维雷达 | `msr/radar.ts` |
| Industry Radar | 哪个产业链节点正在发生变化？ | 已建 = 驾驶舱第③问节点动能。**但 30 个节点里 13 个无覆盖标的** | `cockpit/nodes.ts` |
| Profit Radar | 哪个节点的利润正在从预期变成兑现？ | **未建，且是数据缺口**：扣非利润与主线收入占比靠人工维护字段 | — |
| Money Radar | 钱到底往哪里移动？ | **未建，且是数据缺口**：北向/融资余额/龙虎榜/机构持仓/大宗全缺，现用成交额与涨跌量比作代理 | — |
| Valuation Radar | 新核心是不是已经被资金提前炒贵？ | 已建 = PE-TTM 历史分位，25/28 可用，>80% 拦截 | `msr/valuation.ts` |
| Execution Gate | 即使发现了，今天有没有资格买？ | 已建，硬闸门（执行债务>0 → 锁死全部建仓） | `msr/index.ts` |

**七个里已建成五个。缺的两个 —— Profit Radar 与 Money Radar —— 都不是模型缺失，是数据缺失。**

这个结论决定了下一步该做什么：写新模型解决不了它们。而补数据恰好是冻结期明确允许的三类改动之一。

S0–S3 晋级制也已存在，且与委员会描述基本同构：

```
S0雷达发现·不能买 → S1产业验证·不能买 → S2盈利验证·入候选池 → S3价格窗口·可建仓
```

委员会新增的是 **S4（成为新核心）** 与 **S5（核心过热/阶段性顶部）** 两级。

## 二、两处会静默恢复已证伪规则的表述

### 缺陷一：「老核心 S5 → 降仓」

这条会让**一个未经验证的阶段标签直接产生卖出动作**，正是今天上午刚刚拆掉的东西。

回测事实：TPO 的机械退出信号并不能可靠预测后续跑输。据此我们把退出理由从"预测顶部"改成了风险管理（集中度上限、熔断、安全垫）。

今天的中际旭创就是活证据：技术结构明显恶化、跌破 MA20/MA60、20日跑输行业、下跌放量、触发 6 项技术复核 —— **但仓位已 ≤12%，系统拒绝生成减仓动作。** 委员会自己称这是"架构开始活了"。

若 `S5 → 降仓` 成立，今天中际就会被 OBSERVATION 等级的证据卖掉。**这条规则会亲手推翻它自己刚刚表扬过的那个结果。**

**修正表述**：

- S5 只能是标签，作用是**触发人工复核**，不得进入 `LegalReason` 白名单；
- 减仓的法定理由仍只有：单票/行业/主题超限、组合熔断、家庭安全垫、硬止损、战略证伪；
- S5 唯一可接受的决策效力是**排序而非触发**：当新增资金已经合法获得许可时，S5 标的排在 S2/S3 候选之后。这不预测涨跌，只是不往已经伸展的位置继续加钱。

### 缺陷二：「S3 + 合理价格窗口 + 执行债务=0 → 才允许进入候选买入池」

"合理价格窗口"这个措辞会恢复已删除的红黄绿闸门。

回测事实（27只标的、2023-05~2026-08、13500 观测、日期区块自助抽样 3000 次）：绿灯 +3.53%、黄灯 +5.07%、红灯 +6.14%。**绿减红 -2.61pct，95%区间 [-5.62, -0.37] —— 不是无差异，是红灯显著优于绿灯。** 五个子判据删四留一，只有"10日涨幅>50%"（-7.25pct，区间不含0）具备警示力。

**修正表述**：

```
S3 + 非极端急涨(10日涨幅≤50%) + PE历史分位≤80% + 执行债务=0 + 有仓位空间 + 市场阶段允许
```

"合理价格窗口"应改称"未触发极端急涨否决"。差别不是文字：前者暗示我们能判断价格是否合理，后者只声称我们能识别一种统计上有警示力的极端形态。

## 三、为什么现在不能动手写这个发现器

这是本文件最重要的一节。

S0–S5 的六个阶段里，有四个的定义直接依赖基本面数据：

| 阶段 | 定义 | 所需数据 | 现状 |
|---|---|---|---|
| S0 | 产业故事 | 无（定性） | 可做 |
| S1 | 产业数据改善 | 客户/产品/订单/竞争格局 | **9/28 已建档** |
| S2 | 订单/收入开始兑现 | 收入、主线收入占比 | **8/28 已核验，18/28 未核验** |
| S3 | 利润兑现 + 资金确认 | 扣非利润、现金流、毛利率 + 真实资金流 | **扣非靠人工字段；资金流数据全缺** |
| S4 | 成为新核心 | 上述全部 | 依赖 S1–S3 |
| S5 | 核心过热/阶段性顶部 | 价格 | 可做 |

**当前唯一能自动计算的两级是 S0 和 S5，而它们都只能从价格算出来。**

于是如果今天动手实现这个发现器，它的实际行为会是：用价格动能给标的排序，然后贴上"利润兑现""资金确认"这类基本面标签。

**那就是一个穿着基本面外衣的动量排序器。**

这正是委员会一直在防的那件事，而且比单纯多加几个指标更危险 —— 因为它会用"S3 利润兑现"这样的字样，为一个纯价格判断背书。委员会自己的话：

> 「指标越来越多 → 看起来越来越专业 → 实际没有经过验证 → 最后用模型给自己的判断背书。」

对那 13 个无覆盖节点（EML、硅光、CPO、FAU/AWG、光纤、高速连接、清洗、材料、零部件、变压器、配电、UPS、储能），情况更极端：**它们连一只在册标的都没有，基本面数据覆盖率为 0%。** 任何针对它们的阶段判定，100% 由价格驱动。

### 结论

发现器的前置条件不是模型，是数据。按依赖顺序：

1. **扣非利润与主线收入占比自动化**（当前人工字段，8/28）→ 解锁 S2、S3，同时把 Profit Radar 建起来；
2. **真实资金流数据**（北向/融资余额/龙虎榜/机构持仓/大宗）→ 解锁 Money Radar，替换掉成交额代理；
3. **13 个无覆盖节点逐个建档**：节点 → 龙头 → 产品 → 客户 → 收入 → 扣非利润 → 利润增速 → 估值 → 股价 → 资金。这是委员会指定的深挖路径，且属定性研究，不占决策规则额度。

三项都属"补数据"，冻结期明确允许。**在它们完成之前，S0–S5 发现器不应写入代码。**

## 六、Profit Radar 第一期已落地，同时发现一个会改变 MSR 2.0 架构的事实

2026-08-13 已完成第一项前置：抓取 51 只标的（决策域 28 + 研究域 23）的季度财报，51/51 成功。

**已打通的字段**（东方财富 RPT_LICO_FN_CPD）：累计收入、累计归母净利润、基本EPS、扣非EPS、销售毛利率、每股经营现金流、加权ROE。据此还原出**单季**收入与净利润、单季同比、同比加速度、毛利率同比变化、扣非占比、现金含量。

**本数据源不可得、必须人工建档**：CapEx、分部收入、主线收入占比、订单/合同金额、客户结构、产能利用率。委员会列出的 Profit Radar 清单里，后六项拿不到 —— 这一点必须写明，不能用近似值伪装。

### 那个会改变架构的事实

抓取结果显示：**51 只标的中仅 2 只已披露 2026 中报，其余 49 只最新报告期为 2026Q1，中位滞后 135 天。**

推论直接而重要：

> **利润雷达在结构上不可能是"每天变化"的雷达。它一年只更新四次，且集中在财报季。**

因此委员会设想的那张"每日自动跑"的 MSR 2.0 表格，如果把产业/利润/资金/相对强度四列并排放进"今日"视图，会出现一个隐蔽后果：

- 产业列：变化极慢（建档制）
- 利润列：一年变 4 次
- 资金列、相对强度列：每天变

**于是这张表的日间变动会 100% 来自价格与成交。** 一个用户每天早上看它，看到的"新核心势能变化"实际上只是价格排序在动 —— 只是这一次，它穿的是财报的外衣。

这与"缺利润数据所以退化成动量模型"是**两个不同的失效路径**：前者因缺数据，后者即便数据齐备也会发生，因为**不同雷达的更新频率差了两个数量级**。

### 由此确定 MSR 2.0 的架构约束

1. **利润雷达事件驱动，不进每日表。** 财报披露触发重算，输出带"数据截止日 + 滞后天数"。
2. **每日表必须逐列标注更新频率。** 一列"上次更新 135 天前"的数据不得与当日价格并列呈现而不加标注。
3. **禁止用"综合评分"把不同频率的列合成一个数。** 合成后高频列会主导总分，而读者无法看出这一点 —— 这正是"用模型给自己的判断背书"的技术实现路径。

### 第一期读数（2026Q1 口径，滞后 135 天）

摘录几个与委员会关切直接相关的节点：

| 主线 | 节点 | 单季净利同比中位 | 状态 | 覆盖 |

| 光通信 | 光芯片/CW激光器 | +1153% | 仅有同比读数 | 源杰（决策域） |
| 光通信 | 光模块 | +170% | 内部分化 | 中际、新易盛 |

| 半导体 | 刻蚀/MOCVD | +197% | 加速 | 中微 |

这正好说明两件事：① 技术结构恶化 ≠ 经营恶化；② **"利润兑现"不能当作买入时机信号** —— 利润兑现得最猛的那个季度，股价可以同时走弱。委员会设想的"利润↑→重点研究"若被当成时机判据，会在这里直接失效。

### 由此得到的两个判断

1. **MSR 2.0 的"资金势能"维度在数据上暂时不可能达标。** 当前 MSR 的资金维度用成交额与涨跌量比作代理，这个代理**必须继续标注为代理**，不得因为"补过数据了"而升格为已验证。

2. **如果坚持要做资金雷达，必须先解决数据源问题**（付费数据授权，或券商接口）。在此之前，任何"资金确认"字样都只是成交额的换称 —— 而委员会已明确：这条路回测证明过，不能再走。

## 八、研究域与决策域的物理隔离

23 只研究标的（覆盖全部 13 个无覆盖节点，每节点 2 只以防单点误判）放在 `research/nodeCandidates.ts`，**不进入 `msr/universe.ts` 的 MAINLINES**。因此：

- MSR 扫不到它们 → 不可能产出买入候选。「发现 ≠ 许可」在数据层就成立，不靠下游闸门补救；
- **规则指纹不变**（`06ed04bb9084`，21 条）→ 冻结期未被破坏。**加研究标的不是加规则。**
- `research/selftest.ts` 32 项断言这两个集合永不相交，已接入 CI。

## 四、一条永久条款：发现 ≠ 许可

委员会原则：「发现新核心 ≠ 允许买入。这两个动作必须彻底分离。」

**这一条已经实现且已在实盘输出中验证。** 2026-08-13 首次运行结果：MSR 扫出 1 个候选进入价格窗口，最终生成的买入动作为 **0 个**。

分离由三层保证，均非文档约定而是代码约束：

1. **类型层**：OBSERVATION 等级的指标无法构造出动作（`makeAction()` 抛错）；
2. **理由层**：`LegalReason` 是封闭白名单，不含任何预测性成员；措辞另受 `FORBIDDEN_REASON_PHRASES` 检查；
3. **闸门层**：执行债务 > 0 时物理锁死全部建仓输出。

发现器建成后，其输出的全部阶段标签（含 S4、S5）**默认为 OBSERVATION 等级**。任何一级要获得动作权限，须走 CTC 证据标准条款：样本 ≥300 独立观测、有可推翻的检验、对无条件基准、否则不得进代码。

## 五、下一阶段真正的循环

委员会给出的完整循环，本体系目前的完成度：

```
老核心退出  → 资金释放 → 主线扫描 → 新势能发现 → 深度验证 → 合理价格 → 新核心建立 → 下一轮
   ▲已建       ▲已建      ▲已建      ▲已建        ▲缺数据     ▲已建      ▲缺数据
（但仅限法定             （13/30节点              （扣非利润
  理由，不含               无覆盖）                 与资金流）
  预测性退出）
```

缺口集中在"深度验证"一环，且是数据缺口。

**"阶段性顶部撤退"作为循环起点的定位，本体系接受一半**：它可以是资金释放的起点，但**不能是退出动作的触发条件**。退出仍由法定理由触发。原因见第二节缺陷一 —— 否则今天的中际就会被卖掉。
